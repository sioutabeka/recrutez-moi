## Règles de rédaction (durables, à respecter sur TOUS les CV / LM / site)

- **Jamais d'em-dash** (—) nulle part
- **Jamais la formule "Pas X mais Y"** (opposition rhétorique bannie)
- **Jamais commencer un titre / une accroche par un chiffre** ("Trois preuves…", "Quatre expertises…")
- **LeGratin social canals** = LinkedIn + blog + YouTube + webinars + newsletters UNIQUEMENT (ne jamais inventer TikTok / Instagram / Facebook pour LeGratin)
- **Ne rien inventer** : s'appuyer uniquement sur les faits documentés
- **1 page A4** (contrainte systématique)
- **Photo** optionnelle, selon le type de poste (plutôt pour corporate / institutionnel / retail / cabinet, moins pour pure tech)

## Processus optimisé pour les prochaines offres

1. **Lire l'offre** et identifier l'archétype (A, B, C, D, ou E)
2. **Partir du CV master correspondant**
3. **Adapter uniquement :**
   - Le **titre** sous le nom (reprendre les mots-clés exacts de l'offre)
   - Le **profil** d'intro (2-3 phrases en miroir de l'offre)
   - L'**ordre** des expériences si besoin (LeGratin vs OseCom en premier)
   - Les **bullets** de chaque expé pour utiliser le vocabulaire de l'annonce
   - Les **compétences & outils** priorisés selon ce que l'offre demande

4. **Vérifier avant d'envoyer :**
   - [ ] Pas d'em-dash
   - [ ] Pas de "Pas X mais Y"
   - [ ] Pas d'opener numérique
   - [ ] 1 page A4 (print preview Cmd+P)
   - [ ] Rien d'inventé (surtout LeGratin social canals)
   - [ ] Photo cohérente avec le secteur

## Insights pour nourrir le site `recrutez-essia.com`

Patterns qui reviennent dans les offres et qui peuvent devenir des **sections / pages / preuves** sur le site.

### Mots-clés qui reviennent dans quasi toutes les offres
- "Stratégique **et** très opérationnel" (ou "hands-on")
- "Chef d'orchestre" / "coordination 360°"
- "Autonome · force de proposition · culture résultat"
- "Data-driven · ROI · KPIs · dashboards"
- "Entrepreneur / entrepreneurial"
- "AI-native · intégration IA au quotidien" (de plus en plus présent, 2026)
- "Multi-projets · priorisation · plusieurs dossiers en parallèle"
- "Prise de parole · aisance publique"

### Preuves chiffrées à ressortir systématiquement sur le site
- **20 000+ utilisateurs** acquis en organique
- **Levée de 1,5 M€** (contribution directe)
- **Intégration au groupe Nexoris** (acquisition réussie)
- **50+ interviews d'experts** / **30+ webinars** (volume de production content)
- **3 ans CODIR + actionnaire** d'une scale-up (dimension direction)
- **9 ans** d'expérience, dont 2 en agence + 3 en scale-up + 1 en école + freelance
